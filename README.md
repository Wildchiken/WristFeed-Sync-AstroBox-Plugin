# 腕读同步

AstroBox 插件，配合手环上的「腕读」离线订阅阅读器使用。

- **订阅**：60 多个挑好的 RSS / Atom 源，分 12 类，每个带一句说明，「新手推荐」一键加上 5 个；也能填网站地址（同步时自动找订阅），或整段导入 OPML
- **同步**：抓新文章，只给摘要的会去原网页抓全文；图片缩小后再发，可以只带封面
- **繁转简**、去掉手环显示不了的字符
- 每次处理只做一件联网的事，网络请求都有硬超时，碰上不回话的网站不会卡住插件

## 用法

1. 在 AstroBox 里给手环装好「腕读」（资源商店里搜「腕读」）。
2. 在 AstroBox 的插件商店里装「腕读同步」，并按提示给权限。
3. 在插件里加几个订阅；在手环上打开腕读、保持亮屏，再点「同步」。

插件直接访问你订阅的网站，文章通过蓝牙发到手环，不经过开发者的任何服务器。

## 目录

`index.txt` 指向 `release/`，里面是插件的 `manifest.json`、图标和编译好的 `wristfeed_sync.wasm`（Rust，AstroBox 插件 API Level 3）。第三方组件和许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。
